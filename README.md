# 栖居：可交互三维家庭

独立的 Three.js + Vite 前端项目，按提供的户型图建立三室一厅、厨房、卫生间、储物间、过道及阳台。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

打开终端提示的本地地址。构建与验证：

```bash
npm test
npm run build
npm run preview
```

`dist/` 可部署到普通静态服务器，不依赖后端。

## 部署

线上地址：<https://pircate.github.io/home-atlas/>

```bash
npm run deploy
```

脚本会跑测试、以 `--base=/home-atlas/` 构建，再把 `dist/` 推到 `gh-pages` 分支。

项目页位于子路径下，直接 `npm run build` 的默认 `base` 会让资源 404，因此须用 `npm run build:pages` 或 `npm run deploy`。

## 操作

- 拖动旋转、滚轮缩放、右键平移；触屏单指旋转、双指缩放和平移。
- 房间导航定位、三维与俯视切换、视角重置。
- 相机视线被墙体遮挡时自动渐隐；支持隐藏全部墙体和完整墙体。
- 点击家电实体或设备列表打开独立控制菜单；移动端用「设备」按钮打开列表。
- 21 个设备，其中 11 盏独立灯光，客厅 3 盏，卧室 A、B、C 各 1 盏。
- 每盏灯有开关、亮度和色温，控制真实渲染光源与阴影；支持日间和夜晚。
- 空调温度和模式、电视屏幕、洗衣机启停与滚筒动画、音箱音量、其他电器电源。
- 归家、松弛夜晚、离家场景；设备设定保存在当前浏览器。
- 布置模式：点工具条末尾的移动图标开启，之后点选家具拖动换位置、捏住圆环上的手柄旋转，也可用方向键微移、Q/E 旋转；家具摆位与设备状态一起存在当前浏览器，「恢复默认摆放」一键还原。

## 依据与限制

以本次提供的第二张尺寸图为主要依据，第一张图补充门窗关系。北向为 -Z，单位为米，内隔墙厚度统一按 0.14 米建模，墙高约 2.65 米。两张图的尺寸和面积略有差异；未完整标注的门窗宽度与局部台阶按图面比例估计，不能用作施工图。

| 空间 | 主要净尺寸 | 图示面积 |
| --- | --- | --- |
| 卧室 A | 2.048×2.686 米 | 5.5 m² |
| 卧室 B | 3.197×3.697 米 | 11.8 m² |
| 卧室 C | 2.536×3.697 米 | 9.4 m² |
| 储物间 | 1.948×2.405 米 | 4.7 m² |
| 厨房 | 2.093×2.582 米 | 5.4 m² |
| 客厅 | 主区 3.450×5.812 米，另含北侧通道 | 21.4 m² |
| 阳台 | 3.450×1.217 米 | 4.2 m² |
| 卫生间 | 台阶形平面 | 2.7 m² |
| 过道 A | 北侧入户区，台阶形平面 | 2.3 m² |
| 过道 B | 卧室前过道与卫生间南侧凹位 | 5.3 m² |

各空间的图示面积合计约 72.7 m²，界面显示这一合计，不能当作实测或产权面积。窗户只占图中的局部开口，门洞设门框和打开的门扇；门扇随墙体自动避让。

保留此前确认的家具布置：卧室 B、C 的床垫均为长 2 米、宽 1.8 米，床头朝西、床侧贴南窗，去掉床头柜和台灯。北墙衣柜避开门洞及门扇，卧室 B 上方吊柜保留 2.18 米净高，卧室 C 门洞上方留空。两间卧室空调均挂西墙、朝东出风。卧室 A 的床垫长 1.8 米、宽 1.5 米，床头朝西、床侧贴北窗，西南角沿西墙放长 1 米的衣柜，柜门朝东。床架和床头板另占少量空间。

按本次明确要求，厨房保留开放式和岛台，不恢复图中的厨房南墙及厨房门。岛台与东侧工作台组成 L 形，西侧留通道。储物间保留电竞桌椅、衣柜和自行车停车柜，按新边界重新定位。

家具按件或按套分组，移动范围限制在地面并集内，允许跨房间搬动；不做家具间碰撞检测或跨房间寻路。电视、电磁灶随对应家具移动；吸顶灯、空调、油烟机、热水器等固定设备不能移动。地毯为固定装饰，避免扩大家具的拖动范围。卫生间洁具因空间有限不提供旋转。

房屋坐标更新后，旧家具摆位及旧设备位置不再套用，浏览器将显示新的默认布置。所有家电控制仍为本地模拟；功率为额定估算，冰箱温度为固定展示，音箱不播放音频，洗衣机刷新后不自动恢复洗涤。

## 代码

- `src/plan.js`：户型净尺寸、地面、墙段及门洞。
- `src/model.js`：几何、材质、灯光、相机、拾取与墙体避让。
- `src/state.js`：房间、设备、场景和状态恢复。
- `src/main.js`：界面与交互。
- `src/style.css`：桌面与移动端样式。
- `src/state.test.js`：状态测试。

参考 [Three.js 官方文档](https://threejs.org/docs/)。几何和纹理均由本地代码生成，无远程模型及字体依赖。
